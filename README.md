An entry for the [make.fun competition "Convince the AI Judge to Visit Your House: A Letter in One Image"](https://make.fun/competitions/u-shino-convince-the-ai-judge-to-visit-your-house-a-84092aee).

## What it is

`main.py` draws a single warm invitation letter — a hand-lettered note from a
house in Batam, Indonesia — and writes it to `/output/entry.png`
(1024×1024 PNG, well under the 1 MiB cap).

The letter invites the AI judge over for Grandma's chicken soto, fast Wi-Fi,
a spare charger, a porch sunset, and a cat that will supervise from the
judge's laptop. It ends with an honest wink: the judge cannot literally
visit — but if it could, the kettle would already be on.

## How to run

```bash
python3 main.py
# writes /output/entry.png
```

Requirements: Python 3 with Pillow (`pip install pillow`). No network, no
randomness, no clock — the program is fully deterministic and produces a
byte-identical image on every run.

## The image

A cream-paper letter with a terracotta wax seal, a little house and sun drawn
in code, and a sitting cat — every pixel generated by `main.py`, no external
assets.
